# GestureLock

Один файл: `main.py`. Python 3.12.

Камера: `.\.venv\Scripts\python.exe main.py`  
Видео: `.\.venv\Scripts\python.exe main.py test_images/demo.mp4` — вместо камеры можно видео с рукой  
Картинка: `.\.venv\Scripts\python.exe main.py test_images/photo.jpg`  
Тест без камеры: `.\.venv\Scripts\python.exe main.py --demo`

LOCKED + 8 пальцев = UNLOCKED. ✌️ 3-2-1 = Photos. 👍 5-4-3-2-1 = Videos (5 сек). 🖐 = выход, камера отключается.

Учителю слать только: `main.py`, `requirements.txt`, `README.md`, `test_images/` (картинка/видео с рукой). `.venv` не слать.
